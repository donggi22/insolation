# 일사량 예측 프로젝트 - 처음부터 체계적으로

## 목표
- KMA 기상청 데이터를 학습용으로 사용
- IoT 센서 데이터를 실시간 예측용으로 사용
- 기상변수로부터 일사량 예측

## 데이터 구조
1. **KMA_weather.csv**: 기상청 데이터 (학습용)
   - 일사량(MJ/m2): 실제 측정값 (타겟)
   - 기상변수들: 기온, 습도, 기압, 풍속, 전운량 등

2. **total_iot_sensor.csv**: IoT 센서 데이터 (예측용)
   - 기상변수들: 온도, 습도, 기압, 풍속 등
   - 일사량 센서 없음 → 모델로 예측

## 접근 방법
1. **데이터 탐색**: 각 데이터의 구조와 특성 파악
2. **특성 선택**: IoT 센서가 제공하는 변수들 위주로 선택
3. **모델 개발**: 간단하고 해석 가능한 모델부터 시작
4. **성능 평가**: 실무에서 사용할 수 있는 수준인지 확인
5. **예측 적용**: IoT 데이터에 모델 적용
